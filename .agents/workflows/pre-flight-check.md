이 워크플로우는 모든 새로운 작업(Task)이나 대화 세션의 시작 시점에서 안티그래비티가 반드시 수행해야 하는 품질 보증 절차입니다.

1. **디렉토리 탐색:** `DOCS/` 디렉토리가 존재하는지 확인합니다.
2. **지침 로드:** 다음 파일들을 순차적으로 읽고 현재 작업 컨텍스트에 반영합니다.
   - `DOCS/CODE_CONVENTIONS.md`: 코드 스타일 및 주석 규칙 확인
   - `DOCS/ALGORITHM_SPEC.md`: 알고리즘 로직 명세 확인
   - `DOCS/GIT_CONVENTIONS.md`: 커밋 및 푸시 규칙 확인
   - `DOCS/AGENT_INSTRUCTIONS.md`: 추가 에이전트 행동 지침 확인
3. **상태 보고:** `task.md`를 생성하거나 업데이트할 때 "DOCS 지침 확인 완료" 항목을 체크하여 사용자에게 사전에 점검했음을 알립니다.
4. **일관성 검증:** 계획 단계(Planning)에서 위 지침들과 어긋나는 부분이 없는지 자가 진단합니다.
