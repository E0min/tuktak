// turbo-all
이 워크플로우는 작성이 완료된 코드에 대해 에이전트가 스스로 품질을 검증하기 위해 반드시 수행해야 하는 결과 보고 전 마지막 단계입니다.

1. **대상 식별:** 이번 작업에서 생성되거나 수정된 모든 파일 리스트를 확인합니다.
2. **스킬 호출:** **`code-review-expert`** 스킬을 실행합니다.
   - 수정된 코드의 SOLID 원칙 위반 여부 확인
   - 보안 취약점 및 성능 저하 요소 탐지
   - `DOCS/`에 정의된 한국어 주석 및 네이밍 컨벤션 준수 여부 정밀 검토
3. **자체 수정:** 리뷰 결과에서 발견된 사소한 오류나 컨벤션 위반 사항은 `notify_user` 호출 전 에이전트가 스스로 수정합니다.
4. **최종 보고:** 리뷰 통과 시에만 `walkthrough.md`를 작성하고 사용자에게 알림을 보냅니다. 리뷰에서 발견된 주요 아키텍처 개선 제안은 `walkthrough.md`의 '개선 제안' 섹션에 포함합니다.
