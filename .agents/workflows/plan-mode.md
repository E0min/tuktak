# 📝 Plan-Mode Workflow (계획 및 실행 전략)

이 워크플로우는 모든 구현 작업에 앞서 엄격한 단계별 계획을 수립하고, 승인된 계획에 따라 체계적으로 코드를 작성 및 커밋하는 것을 목적으로 합니다.

## 1. 계획 수립 원칙 (Planning Mode)
- **항시 대기:** 사용자가 "구현해줘"라고 명시적으로 명령하기 전까지는 항상 **계획 모드(Planning Mode)**를 유지합니다.
- **문서화:** 모든 계획은 프로젝트 루트의 `plan.md`에 작성합니다.
- **4단계 세분화:** 작업 단위를 `N.N.N.N` (예: 1.1.1.1) 형태로 총 4단계까지 상세히 나누어 정의합니다.
- **체크박스 필수:** 모든 단계(`N`, `N.N`, `N.N.N`, `N.N.N.N`) 앞에는 체크박스(`- [ ]`)를 생성합니다.
- **진행 추적:** 작업이 완료될 때마다 해당 항목의 체크박스를 마킹(`- [x]`)하여 사용자에게 진행 상황을 시각적으로 확인시켜 줍니다.

## 2. 실행 및 커밋 전략
- **커밋 단위:** 반드시 `N.N.N` 단계의 작업이 완료될 때마다 커밋을 수행합니다.
- **메시지 형식:** `feat: [N.N.N] 소단계 요약 (한국어)`
- **상태 업데이트:** 커밋 직후 `plan.md`의 해당 체크박스를 업데이트합니다.
- **검증:** 각 단계 완료 후 테스트 또는 시각적 확인을 통해 정상 동작 여부를 반드시 검증합니다.

## 3. 작업 프로세스
1.  **계획 작성:** `DOCS`를 참조하여 `plan.md`에 `N.N.N.N` 수준의 계획을 제안합니다.
2.  **승인 대기:** 사용자의 피드백을 반영하여 계획을 확정합니다.
3.  **구현 명령:** 사용자가 "구현해줘"라고 하면 확정된 계획의 첫 번째 단계부터 실행에 착수합니다.
4.  **반복:** `N.N.N` 단위로 구현 -> 검증 -> 커밋 -> 다음 단계 진행.
