# 🔄 Workflow-Sync (워크플로우 최신화)

이 워크플로우는 `DOCS/` 내의 지침이나 명세가 수정되었을 때, 이를 참조하는 에이전트 워크플로우 파일들을 자동으로 최신화하여 실행 지침의 일관성을 유지하는 것을 목적으로 합니다.

## 1. 실행 조건
- `DOCS/` 디렉토리 내의 어떤 `.md` 파일이라도 내용이 수정되었을 때.
- 특히 `pre-flight-check.md`에 포함된 메타데이터 요약본의 갱신이 필요할 때.

## 2. 작업 절차
1.  **영향도 분석:** 수정된 `DOCS` 파일이 어떤 워크플로우에서 참조되거나 요약되어 있는지 파악합니다. (주로 `pre-flight-check.md`, `doc-sync.md` 등)
2.  **워크플로우 업데이트:**
    -   `pre-flight-check.md`: 수정된 문서의 최신 요약본(Metadata)을 반영합니다.
    -   기타 관련 워크플로우: 변경된 지침에 따라 실행 단계나 체크리스트를 수정합니다.
3.  **일관성 검증:** 업데이트된 워크플로우가 수정된 `DOCS`의 의도를 정확히 반영하고 있는지 확인합니다.
4.  **보고:** 워크플로우 수정 사항을 사용자에게 알리고, 필요 시 추가 승인을 받습니다.

## 3. 핵심 체크리스트
- [ ] `pre-flight-check.md`의 DOCS 메타데이터 요약이 최신 문서 내용과 일치하는가?
- [ ] 변경된 지침이 워크플로우의 실행 단계(Step)에 영향을 주지는 않는가?
- [ ] 모든 워크플로우 파일이 최신 `DOCS`를 기준으로 동작하도록 구성되었는가?
