# 배차 Mock 데이터 생성 명세 (MOCK_DATA_SPEC.md)

이 문서는 시뮬레이션에 사용될 100개의 가상 배차 콜(주문) 생성 로직을 정의합니다.

## 1. 생성 규모 및 범위
- **수량:** 하루 기준 총 100건의 랜덤 콜 생성.
- **지역 범위:** 서울특별시 전역 (위도: `37.42` ~ `37.70`, 경도: `126.75` ~ `127.20`).

## 2. 주문 필수 속성 (Order Attributes)

### 2.1 위치 정보 (Location)
- **상차지(Pickup):** 서울 시내 랜덤 좌표 및 법정동 명칭.
- **하차지(Dropoff):** 서울 시내 랜덤 좌표 및 법정동 명칭.

### 2.2 화물 정보 (Cargo Details)
- **물건 종류 (Category):**
  - 가전 (Appliance)
  - 가구 (Furniture)
  - 매장 집기 (Store Fixture)
  - 소형 사무실 집기 (Small Office Furniture)
  - 기타 일반 화물 (General)
- **차종:** **1톤(1T) 고정**.
- **부량/중량:** 1톤 적재함 기준 랜덤 점유율 (20% ~ 70%) 및 무게 (100kg ~ 800kg).

### 2.3 시간 및 배송 조건
- **상차 시간:** 오전 08:00 ~ 오후 18:00 사이 랜덤 설정.
- **하차 시간:** 상차 후 최소 2시간 ~ 최대 6시간 이내 범위 (시간 윈도우).
- **도착 구분:** 
  - 당일 도착 (Same-day): 상차 당일 내 배송 완료.
  - 익일 도착 (Next-day): 상차 익일 오전까지 배송 완료 (일부 적용).

## 3. 알고리즘 연동 규칙
- 생성된 100개의 데이터는 `ALGORITHM_SPEC.md`의 최적화 엔진에 입력값으로 전달됩니다.
- 시뮬레이션 실행 시마다 매번 새로운 랜덤 시드가 적용되어 다양한 배차 시나리오를 생성합니다.
