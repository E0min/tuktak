# 운임 산정 모델 명세 (PRICING_MODEL.md)

이 문서는 주행 거리를 기반으로 한 화물 운임(Price) 산정 방식과 알뜰운송(합짐) 할인 로직을 정의합니다.

## 1. 기본 운임 산정 (Base Pricing)
단독 배송(Before)의 경우 다음 공식을 기준으로 운임을 산정합니다.

$$Price = Base\_Fee + (Distance \times Distance\_Rate)$$

- **기본료 (Base Fee):** 35,000원 (서울 시내 1톤 트럭 기준 소단거리 기본가).
- **거리당 요금 (Distance Rate):** 1km당 1,500원.
- **주행 거리 (Distance):** Naver Navigation API에서 제공하는 최적 경로 주행 거리.

## 2. 알뜰운송(합짐) 할인 모델 (After Pricing)
사용자가 합짐을 선택할 경우, 플랫폼 수수료와 효율성을 고려하여 할 인가를 적용합니다.

$$Bundled\_Price = Price \times (1 - Discount\_Rate)$$

- **할인율 (Discount Rate):** 15% ~ 25% 범위 (합짐 성공 시 적용).
- **기사 수익 배분:** 개별 화주로부터는 할인가를 받되, 기사는 다수의 화물을 동시에 처리함으로써 **'시간당 수익'**을 극대화합니다.

## 3. 부가 가중치 (Optional Weights)
- **화물 종류 가중치:** 가구, 가제 등 파손 주의 품목의 경우 상하차 난이도를 고려하여 5%~10% 할증 가능.
- **시간대 가중치:** 출퇴근 시간 혼잡 통행료 또는 야간 배송 할증 등 고려 (MVP 이후 확장).
