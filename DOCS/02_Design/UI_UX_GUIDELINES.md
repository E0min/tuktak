# UI/UX 디자인 가이드라인 (UI_UX_GUIDELINES.md)

이 문서는 'TukTak' 플랫폼의 시각적 정체성과 사용자 경험 표준을 정의합니다. 프리미엄하고 현대적인 감성을 유지하기 위한 핵심 지침입니다.

## 1. 디자인 컨셉: "Premium Logistics"
- **키워드:** 신뢰, 효율, 첨단, 부드러움.
- **스타일:** 다크 모드 기반의 글래스모피즘(Glassmorphism)과 네온 액센트 활용.

## 2. 컬러 시스템 (Color Palette)
- **Primary:** `Indigo-500` (#6366f1) - 기술적 신뢰와 혁신.
- **Secondary:** `Emerald-500` (#10b981) - 효율성, 친환경, 성공 지표.
- **Accent:** `Amber-400` (#fbbf24) - 상차(Pickup) 포인트 및 경고/알림.
- **Background:** `Slate-950` (#020617) - 심도 있는 다크 배경.
- **Surface:** `Slate-900/50` + `backdrop-blur` - 컴포넌트 레이어.

## 3. 타이포그래피 (Typography)
- **Main Font:** `Inter` 또는 `Geist Sans` (San-serif 계열).
- **Heading:** `Black` 또는 `Bold` weight를 사용하여 강한 인상을 전달.
- **Body:** `Medium` 또는 `Regular` weight, 높은 가독성 확보.
