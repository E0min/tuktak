# 알고리즘 명세 (ALGORITHM_SPEC.md)

이 문서는 화물 합짐(Bundling) 알고리즘의 논리적 구조와 수식 정의를 포함합니다.

## 1. 하드 제약 조건 (Filter)
- **적재량:** $\sum{\text{물품 적재 부피}} \le \text{1톤 적재함}$, $\sum{\text{물품 중량}} \le 1,100\text{kg}$
- **시간 윈도우:** 상차 $A \to$ 상차 $B \to$ 하차 $A \to$ 하차 $B$ 순의 순차적 방문 가능성 보증. 혹은 상차 A에서 하차A로 가도 됨, 경로상 최적화가 우선
- **마감 기한:** 모든 배송은 당일 21시까지 완료되어야 함.

## 2. 스코어링 함수 (Scoring Function)
후보 경로들 중에서 가장 효율적인 경로를 선정하기 위해 다음 점수를 산출합니다.
$$Score = w_1(\Delta \text{Distance}) + w_2(\Delta \text{Time}) + w_3(1 - \text{Load Factor})$$

- **$w_1$ (거리):** 개별 운송 총 거리 대비 합짐 시 이동 거리 차이 최소화.
- **$w_2$ (시간):** 공차 이동 시간과 우회 시간의 합계 최소화.
- **$w_3$ (적재율):** 1톤 차량 내부 공간의 효율적 활용도 극대화.

## 3. 경로 최적화 기법
- **Cluster-First:** 상차지가 유사한 구 단위 지역들을 먼저 그룹화합니다.
- **Greedy Route:** 각 클러스터 내에서 거리가 가장 가까운 지점을 순차적으로 방문하도록 경로를 생성합니다.
